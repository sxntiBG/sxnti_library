# sxnti_library

sxnti_library es una librería en Python enfocada en realizar operaciones matemáticas de manera eficiente y sencilla.

## Instalación

Puedes instalar la librería utilizando pip:

```bash
pip install sxnti_library
```

## Uso

A continuación se muestra un ejemplo básico de cómo utilizar la librería:

```python
import sxnti_library as sx

# Ejemplo de suma
resultado = sx.Sumar(5, 3)
print(f"La suma es: {resultado}")

# Ejemplo de resta
resultado = sx.Restar(10, 4)
print(f"La resta es: {resultado}")

# Ejemplo de multiplicación
resultado = sx.Multiplicar(6, 7)
print(f"La multiplicación es: {resultado}")

# Ejemplo de división
resultado = sx.Dividir(20, 5)
print(f"La división es: {resultado}")
```

## Funciones disponibles

- `suma(a, b)`: Retorna la suma de `a` y `b`.
- `resta(a, b)`: Retorna la resta de `b` de `a`.
- `multiplicacion(a, b)`: Retorna la multiplicación de `a` y `b`.
- `division(a, b)`: Retorna la división de `a` entre `b`.
